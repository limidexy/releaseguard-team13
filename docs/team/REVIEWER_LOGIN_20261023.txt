开始前
1. 与维护人约定在线时间。维护人核实免费试用后恢复原节点，不发布新镜像。
2. 每位组员私下取得自己的初始凭据；不要把初始或最终密码发群、提交 Git。
3. 本人电脑安装 Node.js（建议24），取得本仓库或单独登录助手包。
   登录助手仅使用 Node 自带模块，无需 npm install、GCP SDK 或任何 API Key。

真正独立审核
8. xinda 在自己的会话提交 source=replay 的候选；规则满足后申请审核。
9. reviewer 点击任务“查看证据”，检查同一应用、suite版本、候选、原始回答和逐项结果。

    不只看分数，不由维护人代点，不为了演示预先约定一定批准。
11. 导出证据，保留任务、版本、reviewer、时间、意见和终态。截图不得包含密码或完整令牌。
12. 清空网页令牌，关闭本机登录页和助手（终端 Ctrl+C）。所有人完成后由维护人停机并核验实际节点0。

本轮边界
仅 replay，不选 real，不调用客服或评审模型。个人登录助手只读任务与审核申请，不代为审批。
账号配置成功不等于本人已登录，人工批准不等于自动部署，更不代表实验语义 reviewer 获得正式资格。
同一人换两个账号不能称为另一位组员的独立审核。
当前 shadowOnly=true、calibration_pending 不变。

常见问题
网页登录失败/连接超时：先核实维护人是否已恢复节点。
端口8765被占：关闭以前的本人登录助手，勿擅自修改已注册回调端口。
401：个人令牌过期或环境错误，重新本人登录。
403：角色或服务身份不符，找管理员核验，不能换用共享管理员/CI令牌。
409：可能是自审、过期版本、重复操作或终态冲突，先检查当前记录。
没有 pending：请提交者先建立门禁通过的 replay 候选并申请审核。

安全说明
登录助手只监听127.0.0.1，使用PKCE和nonce，不读取密码，不将令牌写到文件或终端。
它不启动/停止云节点，也不接触 GCP、Groq 或维护人凭据。
仓库初始化配置现使用个人角色映射。已有数据库须由管理员配置；单改初始化文件不会迁移现有用户。

## 3. 改进建议（不阻断）

- S-01：分页文字"页 1"建议改为"第 1 页"。
- S-02：规则失败原因（如 `Policy checks failed: …`、`Explicit replay fixture error`）在中文界面下没有翻译；它们属于证据原文，可以保留，但建议加一句中文说明。
- S-03：错误提示出现后再切换语言，带后缀的冲突提示不会跟着重新翻译。
- S-04："执行总耗时"实际是从创建到完成的时间，包含排队等待，建议改名为"总用时（含排队）"。
- S-05：提交任务时用 `crypto.randomUUID()` 生成幂等键，而浏览器只在安全来源（HTTPS 或 localhost）下提供这个函数。如果有人用纯 HTTP 的非 localhost 地址访问（例如局域网 IP），提交任务无法正常完成：第一次提交在发出请求前就失败，页面显示"请求未完成"。当前本地（localhost）和云端（HTTPS）不受影响。这是 2026-10-14 复查时在模拟环境中发现的，属于原有行为，不是 PR #4 引入的。

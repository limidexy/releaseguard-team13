## 2. 缺陷登记

| 编号 | 严重度 | 现象 | 复现 | 状态 |
|---|---|---|---|---|
| D-01 | 中 | 409 冲突（版本过期 / 已决定 / 未通过门禁就申请）时，界面直接显示原始英文 `HTTP 409 {json}`，中文界面也一样 | UAT-18 | **已修复（本地分支，待 PR）**：`public/app.js` 新增本地化 `conflict` 提示，并保留服务端原因；修复后重测通过 |
| D-02 | 中 | 5xx 或非 JSON 错误（服务停掉时为 503）直接显示原始文本，而不是"请求未完成"的提示 | UAT-23 | **已修复（本地分支，待 PR）**：`api()` 先读取文本再解析，5xx 和非 JSON 一律显示离线提示；修复后重测通过 |
| D-03 | 高（Windows 成员无法启动） | 仓库没有 `.gitattributes`，Windows 版 Git 默认的 `core.autocrlf=true` 会把 `deploy/postgres/init.sh` 转成 CRLF，导致 postgres 初始化退出（exit 2），registry 随之 unhealthy | 在 Windows 上全新克隆后执行 `docker compose up` | **未修复，需 D（LIAO CAN）处理**：建议在仓库加入 `.gitattributes`（`*.sh text eol=lf`，`.githooks/* text eol=lf`）。本机临时做法：`git config core.autocrlf false`，重新检出 init.sh，并删除初始化失败留下的空 pgdata 卷 |

## 3. 改进建议（不阻断）

- S-01：分页文字"页 1"建议改为"第 1 页"。
- S-02：规则失败原因（如 `Policy checks failed: …`、`Explicit replay fixture error`）在中文界面下没有翻译；它们属于证据原文，可以保留，但建议加一句中文说明。
- S-03：错误提示出现后再切换语言，带后缀的冲突提示不会跟着重新翻译。
- S-04："执行总耗时"实际是从创建到完成的时间，包含排队等待，建议改名为"总用时（含排队）"。
